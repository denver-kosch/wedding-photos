# Denver & Kylan's Wedding Photos

This project was built to develop my skills and utilize my recent technology acquisitions.

The project is Next.js, with the image upload going through Immich on my TrueNAS SCALE server I've recently set up.

I built this for the purpose of allowing wedding guests to upload their photos throughout the afternoon/evening for us to look at later. The styling is still in progress, but the site is currently in a fucntional v1.0.0 state.
